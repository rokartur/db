# Etap 1: UI w stylu gobang

## Układ
```
+ Connections / Tree (25%) -+- [1 Records] [2 Query] ----------------------+
| v public                  | id | name    | created_at                    |
|     users                 | 1  | Ala     | 2024-01-01                    |
|     orders                | 2  | Ola     | 2024-02-01                    |
| > analytics               |                                              |
|                           |----------------------------------------------|
|                           | page 1 | rows 2 | col 1/3                     |
+---------------------------+----------------------------------------------+
| status / błąd                                           ? help | q quit   |
```
Zakładka Query: edytor (górna 1/3) + wynik (reszta), ten sam widget tabeli co Records.

## Klawisze
| Klawisz | Akcja |
|---|---|
| `Tab` | fokus: drzewo / prawy panel |
| `j`/`k`, strzałki | ruch w drzewie i tabeli |
| `h`/`l` | przewijanie kolumn w tabeli |
| `Enter` w drzewie | rozwiń grupę / otwórz element w Records |
| `]` / `[` | następna / poprzednia strona Records |
| `1` / `2` | zakładka Records / Query |
| `e` lub `i` w Query | wejście do edytora |
| `Esc` | wyjście z edytora |
| `Ctrl-R` / `F5` | wykonaj zapytanie (kontekst = grupa zaznaczona w drzewie) |
| `y` | kopiuj komórkę (OSC 52, bez zależności od schowka) |
| `?` | pomoc |
| `q`, `Ctrl-C` | wyjście (`q` nie działa w edytorze) |

## Kroki
1. `src/app.rs`: struktura `App` (drzewo, rozwinięte grupy, zaznaczenie, zakładka, Grid Records + strona, Grid Query, edytor, status). Funkcje: `handle_key(&mut App, key) -> Action`, akcje async wykonywane w pętli (`await` na driverze; UI czeka, jak w gobang).
2. `src/ui.rs`: `draw(frame, &App)`: drzewo (`List`), tabela (`Table` z szerokością kolumn z danych, max 40 znaków, przewijanie poziome po indeksie kolumny), zakładki (`Tabs`), pasek statusu, popup pomocy.
3. `src/editor.rs`: `Vec<String>` linii + kursor (wiersz, kolumna w znakach), wstawianie, Backspace, Enter, strzałki, Home/End.
4. Ekran wyboru połączenia, gdy brak argumentu: lista z configu, `Enter` łączy.
5. Błędy driverów trafiają do paska statusu, aplikacja nie pada.

## Gotowe, gdy
